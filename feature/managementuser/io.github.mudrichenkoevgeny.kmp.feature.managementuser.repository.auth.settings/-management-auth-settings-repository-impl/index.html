ManagementAuthSettingsRepositoryImpl

class ManagementAuthSettingsRepositoryImpl(managementAuthSettingsApi: ManagementAuthSettingsApi, managementAuthSettingsStorage: ManagementAuthSettingsStorage, webSocketService: WebSocketService, repositoryScope: CoroutineScope) : ManagementAuthSettingsRepository

Implements ManagementAuthSettingsRepository with a mutex-guarded in-memory MutableStateFlow, persistence via ManagementAuthSettingsStorage, HTTP via ManagementAuthSettingsApi, and live updates from WebSocketService for MANAGEMENT_AUTH_SETTINGS_UPDATED events.

Parameters

managementAuthSettingsApi

Remote read endpoint for auth settings.

managementAuthSettingsStorage

Encrypted or local persistence for settings snapshots.

webSocketService

Source of push updates for auth settings changes.

repositoryScope

Long-lived scope used for the WebSocket collector started in init.
