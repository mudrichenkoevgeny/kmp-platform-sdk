ManagementUserComponent

class ManagementUserComponent(val commonComponent: CommonComponent, val settingsComponent: SettingsComponent, val securityComponent: SecurityComponent, val storageComponent: StorageComponent, val authStorage: AuthStorage, val authServices: UserAuthServices, parentScope: CoroutineScope? = null)

Feature-level dependency root for the user module.

Requires a fully wired CommonComponent (HTTP client, WebSocket service, encrypted settings), SettingsComponent, SecurityComponent, a concrete AuthStorage, and platform UserAuthServices.

Exposes repositories, auth-related use cases, the user WebSocket handler, and a factory for the login dialog Decompose tree (ManagementLoginRootComponent).

Parameters

commonComponent

Shared infrastructure from core:common.

settingsComponent

Global settings repository access from core:settings.

securityComponent

Security settings and validators from core:security.

storageComponent

Storage repositories and use cases from core:storage.

authStorage

Token and auth-settings persistence implementing AuthStorage.

authServices

Optional platform services (e.g. Google Sign-In); may provide a null Google delegate.

parentScope

Optional coroutine scope for repository-driven work; if null, an internal supervisor scope is used.
