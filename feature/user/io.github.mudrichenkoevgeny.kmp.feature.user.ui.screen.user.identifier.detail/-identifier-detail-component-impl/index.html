Default implementation of IdentifierDetailComponent.

Supports displaying identifier details and deleting/modifying credentials across both end-user and administrative contexts.

Parameters

componentContext

Decompose ComponentContext.

params

Target identifier parameters.

userRepository

Source of the current user state.

fetchIdentifier

Suspend callback to fetch identifier details remotely.

deleteIdentifier

Suspend callback to delete the target identifier.

changePassword

Suspend callback to change password for email identifier.

deletePassword

Suspend callback to delete password credential.

isCurrentIdentifier

Indicates if this is the active session's identifier.

authStorage

Storage used to resolve active identifier ID if isCurrentIdentifier is omitted.

onIdentifierDeleted

Callback invoked when the identifier is deleted.

onNavigateToUserDetail

Callback to navigate to user detail screen.

onBack

Callback to pop this screen from navigation stack.
