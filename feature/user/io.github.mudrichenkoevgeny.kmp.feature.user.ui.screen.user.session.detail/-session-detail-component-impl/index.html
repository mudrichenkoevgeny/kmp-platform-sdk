Default implementation of SessionDetailComponent.

Supports displaying session details and revoking active sessions across both end-user and administrative contexts.

Parameters

componentContext

Source of the current user state.

Suspend callback to fetch session details remotely.

revokeSession

isCurrentSession

Indicates whether this session belongs to the current device.

Callback invoked when the session is successfully revoked.

onNavigateToIdentifierDetail
