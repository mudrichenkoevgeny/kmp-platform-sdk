StorageComponent

class StorageComponent(httpClient: HttpClient, encryptedSettings: EncryptedSettings, webSocketService: WebSocketService, parentScope: CoroutineScope? = null)

Main entry point and dependency wiring for the core:storage module.

Encapsulates network clients, local encrypted storage, and WebSocket message handling internally, exposing only high-level repositories and use cases.

Parameters

httpClient

Shared Ktor client for REST operations.

encryptedSettings

Encrypted settings backing store.

webSocketService

WebSocket service for reactive settings updates.

parentScope

Parent coroutine scope for repository jobs.
